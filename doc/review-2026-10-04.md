# Code review — 2026-10-04

Reviewed simulation models, input and rendering paths, recording/time behavior, disposal, preferences, bootstrap/configuration, and existing tests. This was a static review supplemented by unit regressions and short browser smoke runs, not an exhaustive proof of correctness.

## Findings addressed

- **P1 — remote pad unreachable by keyboard:** its keyboard drag listener was attached to the decorative knob, which cannot receive focus. Pointer input stays on the knob; keyboard input now runs on the focusable pad. A Playwright regression focuses the pad and starts recording with an arrow key.
- **P2 — mismatched seek-bar scale:** the handle used the duration of the partial recording while the track and drag mapping used the full recording limit. All three now use the same scale.
- **P2 — stale sampling state:** Reset All seeded the sampler before resetting the ladybug; clearing samples set the pen target to the origin; sampler reset left cached averages unchanged. Reset ordering, pen initialization, and cached averages now preserve the correct position and zero derivatives.
- **P2 — transport limits:** repeated Step presses could advance beyond the recording, and hitting the recording cap automatically started playback. Playback and seeking are bounded; recording captures the final state and pauses at the limit.
- **P2 — trace disposal leak:** global color, model callbacks, and a derived accessibility property retained the trace after disposal. Those subscriptions and the derived property now release on disposal.
